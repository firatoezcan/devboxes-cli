# Security Policy

## Reporting a vulnerability

Please report suspected security vulnerabilities privately to
**hello@devboxes.ai**. Do not open a public issue for security reports.

Include what you found, the affected version (`devboxes --version`), and
steps to reproduce. You will receive an acknowledgement, and a fix or a
mitigation plan before any public disclosure is coordinated with you.

## Scope

This policy covers the `devboxes` npm package (the Devboxes CLI and its MCP
server subcommand). Reports about the Devboxes platform itself are also
welcome at the same address.

## Supported versions

Only the latest published version of `devboxes` receives security fixes.
